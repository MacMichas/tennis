# tennis

The public pages of the tennis training app for Apple Watch and iPhone, served by GitHub Pages at https://macmichas.github.io/tennis/. The app's code lives in a private repository.

- `privacy.md` is the privacy policy, at https://macmichas.github.io/tennis/privacy/. The app links it from About and App Store Connect holds the same address, so the address never changes.
- `_config.yml` holds the app's name and the contact, once for every page.

The policy states what the app records, asks for and sends. When the app changes any of those, this policy changes before that version ships, through a pull request here.
